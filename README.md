# 韓国語60秒（speak60）

韓国語スピーキング強化の進行管理アプリ。
学習設計書（`work/韓国語学習/output/韓国語スピーキング強化_学習設計書.html`）を、
毎日そのまま実行できる形に落としたもの。

作成: 2026-08-26

## 何のためのアプリか

準2級まで取れているのに話せない状態を抜けるための、1テーマ＝1回の訓練を回し続けるためのもの。
「今日は何をやるのか」「ChatGPTに何を送るのか」で迷わないことだけを目的にしている。

## できること（v2・可変スケジュール対応）

| タブ | 中身 |
|---|---|
| **今日** | 進み具合に合わせて今やることを出す。上の3つのボタン（**作る／話す／聞く**）で自分でも切り替えられる。タップでチェック |
| **やり方** | 絵でひと通り説明する画面。いまの状態／3つのメニューと順番／時間が取れた日は前倒ししてよい／どの本を使うか（30秒判定）／使うのはこの2冊と合流の時期／2冊の使い分け／各メニューの手順／**かたまり選びで迷ったら**／よくある心配／タブの見方 |
| **手順** | ChatGPTに送る文（P1〜P5）をワンタップでコピー。テーマ名が自動で差し込まれる。P1は「思考方式／文末表現／本なし」の3通り。思考方式版は**本のページを写真で送る前提**で、読み取り確認の一文が入っている |
| **ネタ帳** | 20テーマの一覧と進み具合（未着手／原稿あり／録音済／再演済）。原稿を書き留められる |
| **記録** | 月1回の測定（語数・2秒以上の沈黙・言い直し）を入れると、語数の推移が棒で見える |

### 単位は「週」ではなく「回」（2026-08-27 変更）

当初は曜日で決め打ちしていた（土＝仕込み／日＝本番／平日＝通勤）が、
平日にも不定期でまとまった時間が取れると分かったため、**カレンダーから切り離した**。

- **テーマ1つ＝1回**。第N回は日付ではなく、終わった回数で数える
- 「今日やること」は**進み具合**（作る→話す→聞く）で決まる。曜日は見ていない
- 3つのボタンで手動切り替えもできる。同じボタンをもう一度押すと自動表示に戻る
- **「作る」「話す」のチェックは回ごとに保存**され、日をまたいでも残る（1回に何日かけてもよい）
- **「聞く」のチェックだけ日付ごと**（毎日やり直す）
- 「話す」まで全部チェックが付くと「この回を終えて、次のテーマへ」が出る。押すまで「聞く」を続けられる

推奨の割り当て（土＝作る／日＝話す／平日＝聞く）は「やり方」タブに目安として残してある。

### 回が進むと中身が変わる

- 第1〜2回は **P1・P2・P3 の3つだけ**。P4・P5は「この回はまだ使いません」と薄く表示される
- 第3回から P4・P5 が加わり、「話す」のやることも2つ増える
- 第2回からは、「作る」の先頭に「前回の話を再演して録音する」が出る
- 第10回から、使う本が『思考方式』→『文末表現』に切り替わる

回数は記録タブの設定で直せる（ずれたときだけ）。

## 使う教材（2026-08-26 決定）

手持ちの本を見て、次の2冊に絞った。どちらもCD付き・声優の吹き込み。

| | 本 | 役割 | 使う時期 |
|---|---|---|---|
| 1冊目 | 『韓国人の思考方式を知る ケーススタディ＆フレーズ55』（中山義幸／アルク） | **話題**を借りる | 第1回〜（土台としてずっと） |
| 2冊目 | 『新装版 会話から学ぶ韓国語の文末表現』（韓惠景／HANA） | **言い方**だけを借りる | 第10回から合流 |

- 1冊目を選んだ理由: やさしく、話題が「人と初めて会って話すこと」そのもの。文化背景の解説が「次に何を言うか」の手がかりになる
- 2冊目を後にした理由: 文末表現（`〜거든요` `〜더라고요` 等）は効くが、話題を自分で用意する必要があり、最初の勢いが出にくい
- 見送った本: 『KBSの韓国語ラジオドラマ』（HANA）。会話は最高品質だが**準2級には語彙が難しすぎる**（冒頭2ページで注釈18個）。B山（「聞く」での聞き流し）に回す

第10回になると、「今日」タブの「作る」のやることが自動的に『文末表現』に切り替わる。

## いまはやらないこと

- **録音**（iPhoneの「ボイスメモ」を使う）。PWAでマイクが使えるか実機で確かめてから足す
- クラウド同期・通知・ChatGPTとの直接連携

## データの置き場所

記録はすべて **その端末のブラウザの中だけ**に保存される（localStorage）。外には出ない。
そのぶん、機種変更やSafariのデータ消去で消える。
記録タブの **「データを書き出す」** でコピーし、メモアプリに貼って残しておくこと。

## かたまり採掘の作りこみ（2026-08-27 追加）

実際に始めてもらったところ、「本のどこをどうChatGPTに渡すのか」「かたまりとは単語か文章か」
「1ページに文章量が足りない」で詰まった。次のように直した。

- **P1（思考方式）を写真前提に変更**。「まず読み取った韓国語を書き出して」→ 本と見比べて確認、という手順を組み込み、読み取り間違いを防ぐ
- **個数を「10個」→「多ければ10個、少なければ取れるだけ（5個あれば十分）」に緩和**。8行の会話に10個は多すぎた
- 「作る」を6段階→8段階に細分化（写真を撮る／読み取り確認／5個選ぶ を独立させた）
- やり方タブに**「かたまり選びで迷ったら」**を新設。Case 1から実際に取れる10個の表、
  1文から複数取れること、選ぶ3基準（自分が言う側か／場面が想像できるか／使い回せるか）、
  「5〜10分で切り上げる」を明記

**教訓**: 「かたまり」は本人にとって未知の概念なので、定義だけでなく
**手持ちの本の実物から抜いた実例**を見せないと伝わらない。

## 「文字を見ていいか」問題（2026-08-27 追加）

第1回の途中で出た質問。どれも本人にとっては判断がつかない。

| 場面 | 文字 | 理由 |
|---|---|---|
| 音読（5回） | 見てよい | |
| 録音 | 見てよい | 録音は「発音の記録」ではなく**次の数日に聞く教材**。つっかえないほうが役に立つ |
| 話す（4→3→2） | **見ない** | 直前に1回だけ黙読するのはOK（事前計画は流暢さを上げる）。話している最中は見ない |

- **丸暗記は不要**であることを明記。詰まってよい／順番が変わってよい／忘れた所は自分の言葉で言い換える。
  「覚えていることを再現する」のではなく「言えることで話す」
- **発音・抑揚の確認**は、P2の返信にある「読み上げ」ボタン（スピーカーのマーク）で1回聞くだけでよい。
  音声モードに入る必要はない。「作る」の手順に1段階として追加した（8段階→9段階）
- 優先すべきは**文全体の抑揚**。個々の子音・母音の矯正は優先度が低い（目標は「通じる」こと）

**注意**: この変更で「作る」が8段階→9段階になったため、
移行時にチェック済みだった人は最後の1つが未チェックに見える。タップして埋めれば直る。
