# 韓国語60秒（speak60）

韓国語スピーキング強化の進行管理アプリ。
学習設計書（`work/韓国語学習/output/韓国語スピーキング強化_学習設計書.html`）を、
毎日そのまま実行できる形に落としたもの。

作成: 2026-08-26

## 何のためのアプリか

準2級まで取れているのに話せない状態を抜けるための、週単位の訓練を回し続けるためのもの。
「今日は何をやるのか」「ChatGPTに何を送るのか」で迷わないことだけを目的にしている。

## できること（v1）

| タブ | 中身 |
|---|---|
| **今日** | 曜日を見て、今日やることを自動で出す。土曜＝仕込み／日曜＝本番／平日＝通勤。タップでチェックが付く |
| **やり方** | 絵でひと通り説明する画面。いまの状態／1週間の形／土日と平日の手順／よくある心配／タブの見方。「今日」の一番上のボタンからも飛べる |
| **手順** | ChatGPTに送る文（P1〜P5）をワンタップでコピー。今週のテーマ名が自動で差し込まれる |
| **ネタ帳** | 20テーマの一覧と進み具合（未着手／原稿あり／録音済／再演済）。原稿を書き留められる |
| **記録** | 月1回の測定（語数・2秒以上の沈黙・言い直し）を入れると、語数の推移が棒で見える |

### 週が進むと中身が変わる

- 第1〜2週は **P1・P2・P3 の3つだけ**。P4・P5は「今週はまだ使いません」と薄く表示される
- 第3週から P4・P5 が加わり、日曜のやることも2つ増える
- 第2週からは、土曜の先頭に「先週の話を再演して録音する」が出る

「開始日」（既定 2026-08-29）から第何週かを数えている。記録タブの設定で変えられる。

## v1でやらないこと

- **録音**（iPhoneの「ボイスメモ」を使う）。PWAでマイクが使えるか実機で確かめてから足す
- クラウド同期・通知・ChatGPTとの直接連携

## ファイルの中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。見た目も動きも全部この1枚に入っている |
| `manifest.webmanifest` | ホーム画面に置いたときの名前・色・アイコンの設定 |
| `sw.js` | 電波がなくても開けるようにする裏方 |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン画像（ストップウォッチ。純Pythonで生成した） |

## データの置き場所

記録はすべて **その端末のブラウザの中だけ**に保存される（localStorage）。外には出ない。
そのぶん、機種変更やSafariのデータ消去で消える。
記録タブの **「データを書き出す」** でコピーし、メモアプリに貼って残しておくこと。

## 動かし方

### パソコンで見るだけ

`index.html` をダブルクリックする。

### iPhone のホーム画面に置く

GitHub Pages に公開してから、iPhone の **Safari** でその住所を開く → 共有ボタン → 「ホーム画面に追加」。

## 分かったこと（次に作るときのメモ）

- アイコンのPNGは、画像ライブラリが無くても **純Pythonの zlib + struct** で書き出せる。
  文字は描けないので、円・弧・四角で成立する図案にする
- 1枚のHTMLでも、下タブ4つの「アプリらしい」構成は作れる。
  肝は ①中身の部分だけを縦に動かす ②下タブは `env(safe-area-inset-bottom)` を足す
  ③入力欄の文字を16px以上にする（iPhoneが勝手に拡大するのを防ぐ）
